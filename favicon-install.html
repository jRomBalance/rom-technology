WordPress Install — romallen.com
1

Upload favicon.svg to Media Library

WordPress Admin → Media → Add New → upload favicon.svg

2

Set as Site Icon

Appearance → Customize → Site Identity → Site Icon → Select Image → choose your uploaded favicon

3

Upload logo-v2.svg as your logo

Appearance → Customize → Site Identity → Logo → upload logo-v2.svg

4

Add Apple Touch Icon (optional but recommended)

Upload favicon-512.svg and add to your theme's functions.php or use a plugin like RealFaviconGenerator

5

Clear cache

If you use a caching plugin, clear it after uploading. Browsers cache favicons aggressively — you may need to hard refresh (Ctrl+Shift+R)
